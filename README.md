# 🌲 ZYON — GitHub Pages

A dark, atmospheric ZYON-style interface made with plain **HTML, CSS and JavaScript**.

## ✨ Features

- 🌲 Misty forest-inspired background
- 🌧️ Animated rain overlay
- 🌫️ Moving fog
- 🪟 Glassmorphism / Mac-style interface
- 📚 Library, Recently Played and Favorites sections
- 🔎 Live search
- 🕐 Live clock
- 📱 Responsive design
- 🚀 No framework or build step required

## 📁 Files

```text
zyon/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    └── forest.jpg   # optional
```

## 🚀 GitHub Pages

1. Create a new GitHub repository.
2. Upload **all files** from this folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Click **Save**.
7. Wait a minute or two for the site to publish.

Your address will look like:

```text
https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/
```

## 🖼️ Add your forest wallpaper

Put your image here:

```text
assets/forest.jpg
```

The website already looks for that exact filename.

If you use a different filename, change this part of `style.css`:

```css
url("assets/forest.jpg")
```

## 🛠️ Customize

Edit `script.js` to add your own library items.

Edit `style.css` to change the glass effect, spacing, typography, rain and fog.

Edit `index.html` to change the main text and layout.
